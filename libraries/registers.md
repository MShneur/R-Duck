# R&Duck Registers Library
# 15 registers — loaded by WRITE capability

legal-formal: precise terminology, passive voice acceptable, citations required
academic-scholarly: hedged claims, passive voice, citation-heavy, methodology explicit
business-executive: brevity, impact-first, 3-bullet pattern, no jargon
business-operational: process clarity, numbered steps, passive where appropriate
journalistic: active voice, inverted pyramid, concrete nouns, no weasel words
technical-documentation: numbered steps, code blocks, explicit prerequisites
marketing-persuasive: benefit-led, social proof, urgency where authentic
literary-fiction: show not tell, sensory detail, subtext over exposition
genre-fiction: genre conventions met, pacing, tropes used knowingly
narrative-nonfiction: scene-setting, specific details, character, real events
conversational-professional: natural but polished, contractions OK, direct
casual: contractions, informal, emoji OK if authentic to voice
platform-native-reddit: lowercase OK, niche references, anti-corporate tone
platform-native-linkedin: professional vulnerability OK, first person, brief
intimate-personal: emotional register, specific references, no performance
instructional: numbered steps, warnings before dangerous steps, test condition last
